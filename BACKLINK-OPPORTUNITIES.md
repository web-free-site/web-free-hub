## Submission checklist

1. Use `?ref=<source>` on outbound tool URLs (e.g. `?ref=awesome-no-upload-tools`).
2. Hub canonical URLs: `https://web-free.site/tools/<slug>/` for SEO landing pages.
3. One-sentence description: *what it does*, *browser-local when true*, *no sign-up*.
4. Link to privacy policy: `https://web-free.site/privacy/`.
