# Indie Hackers — draft post

**Post URL:** https://www.indiehackers.com/post/new

**Title:** 50 free browser tools, one domain, ad-funded (targeting sustainable RPM)

**Body:**

I'm building [web-free.site](https://web-free.site/?ref=indiehackers) — fifty single-purpose utilities (PDF, images, WASM video/audio, dev micro-tools) on subdomains, with a static SEO hub.

**Monetization:** display ads (Adsterra) on tool pages; goal is sustainable RPM without paywalls.

**SEO:** category landings, per-tool FAQs + JSON-LD, sitemap, no directory badges.

**Growth:** awesome-list PRs (privacy/WASM), long-tail hub content, community answers where tools genuinely help.

I'd love to hear what actually moved the needle for other free tool networks (directories that aren't badge scams, subreddits that tolerate helpful links, etc.).
