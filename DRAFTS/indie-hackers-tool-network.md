# Indie Hackers draft

**Headline:** Micro-tool network monetized with ads — 50 browser utilities on one brand

**Story:**

I built [web-free.site](https://web-free.site/?ref=indiehackers) because scattered bookmarklets do not rank and a single mega-app is slow to iterate. Each free tool (PDF, images, video, dev utilities) lives on its own subdomain; the hub provides SEO, discovery, and consistent legal pages.

**Stack:** Static hub generator + Cloudflare Workers, per-tool frontends with WASM where it matters.

**Monetization:** Display ads (Adsterra) on tool pages; optimizing for sustainable RPM while keeping tools free.

**Growth levers in flight:**

- GitHub awesome-list PRs (privacy / WASM lists)
- Long-tail hub pages with FAQ schema
- Community answers on Quora/Reddit where a tool genuinely fits

**Ask:** What directories actually drove traffic for your free tools? Trying to avoid badge-for-backlink schemes.
